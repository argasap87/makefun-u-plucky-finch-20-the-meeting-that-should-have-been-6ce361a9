The Meeting That Should Have Been an Email — a single one-liner about a meeting whose only action item was to send the deck by email. The program writes that one line to `/output/entry.txt`.

## The line

> Forty-five minutes, twelve 'circling backs,' and the only action item was: send the deck by email.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader). Node 22 standard library only; no network, no dependencies.
